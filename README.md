#  Cafeteria Aurora

Projeto de um site para uma cafeteria fictícia, desenvolvido como parte dos meus estudos de desenvolvimento web.

##  Sobre o projeto

A Cafeteria Aurora é um projeto criado para praticar os fundamentos de **HTML e CSS**, desenvolvendo uma página com identidade visual própria e navegação entre diferentes seções.

O objetivo foi colocar em prática os conhecimentos aprendidos durante os estudos e aprender, na prática, como estruturar e estilizar um site.

##  Páginas

O projeto possui as seguintes páginas:

-  **Home** — apresentação da cafeteria.
-  **Menu** — cardápio com cafés, chás, sucos, sobremesas e lanches.
-  **Quem Somos** — história e proposta da cafeteria.
-  **Contato** — formulário e informações de contato.

##  Tecnologias utilizadas

- HTML5
- CSS3

##  Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos como:

- Estrutura semântica do HTML
- Links e navegação entre páginas
- Imagens e textos
- Listas
- Formulários
- Flexbox
- `display`
- `margin` e `padding`
- `border` e `border-radius`
- `box-shadow`
- Efeitos com `:hover`
- Classes e seletores CSS

##  Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web e foi criado para praticar e consolidar os conhecimentos adquiridos em HTML e CSS.
